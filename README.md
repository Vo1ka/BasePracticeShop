Проект интернет-магазина с корзиной, фильтрацией и сменой темы. Реализован на React с использованием Redux Toolkit.

## 🛠 Технологии
- **React** (хуки, контекст)
- **Redux Toolkit** (управление состоянием)
- **Mock API** (имитация бэкенда)
- **CSS-модули** + кастомные свойства (темы)
- **Адаптивный дизайн**

## 🚀 Функционал
- 📦 Добавление товаров в корзину
- 🔍 Поиск и фильтрация
- 🌙 Смена темы (light/dark)
- 🛒 Выпадающая корзина
- 📱 Пагинация товаров
- Фейк-авторизация
